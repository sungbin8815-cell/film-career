# ROLLING! — 픽셀 아트 촬영장 격투게임

촬영장 직업인들이 구도·녹음 문제로 다투다가 장비를 무기로 한판 붙는 2D 대전 격투게임입니다.

- **바로 플레이**: https://sungbin8815-cell.github.io/film-career/play/
- **가로 화면 전용**: 세로로 들면 "가로로 돌려주세요" 안내가 뜹니다. 안드로이드 크롬은 첫 터치 때 전체화면 + 가로 고정, 아이폰은 화면 회전 잠금을 풀고 가로로 돌려주세요. 홈 화면에 추가하면 가로 전체화면 앱처럼 열립니다.
- 기술: TypeScript · Phaser 3 · Vite (온라인 대전용 Node.js + Socket.IO 서버는 PHASE 4)

## 현재 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| PHASE 1 | 프로젝트 세팅, 메뉴, 픽셀 스타일, 이동·점프·공격·방어, 체력·승패 | ✅ 완료 |
| PHASE 2 | 캐릭터 7명, 캐릭터마다 다른 플레이스타일 (패시브·고유 게이지·Q/W/E/R) | ✅ 완료 |
| PHASE 3 | SOLO 1대1 · TAG 2대2(교체·어시스트) · STAGE MODE(직급 승진·엔딩) | ✅ 완료 (스테이지 기믹은 PHASE 5) |
| PHASE 4 | FRIEND MATCH 온라인 PVP (Socket.IO 서버, 6자리 방 코드) | ⬜ 예정 (메뉴에 잠금 표시) |
| PHASE 5 | 오프닝 컷신, 실제 효과음 에셋, 스테이지 환경 기믹 | ⬜ 예정 |

### 게임 모드 (같은 전투 엔진, 규칙만 다름)
- **SOLO MATCH 1 VS 1**: 1명 선택, 3판 2선승 60초
- **TAG MATCH 2 VS 2**: 2명 선택, 한 명이 싸우고 한 명은 대기(체력 천천히 회복). **교체**(5초 쿨) · **어시스트**(대기 캐릭터가 나와 기술 하나 쓰고 퇴장, 7초 쿨) · **태그 콤보**(내 공격이 맞는 중에 교체하면 들어오며 점프 공격) · 한 명이 쓰러지면 동료가 들어오고, 둘 다 쓰러져야 패배. 99초 한 판
- **STAGE MODE**: 부서를 골라 막내로 입사 → 스테이지를 깰 때마다 승진(서드 Q·W → … → 감독), FINAL에서 전설의 감독과 대결

### 캐릭터 7명 — 플레이스타일
| 캐릭터 | 역할 | 패시브·고유 게이지 | Q | W | E | R |
|---|---|---|---|---|---|---|
| 촬영감독 | 자유 전환형 | 렌즈마다 Q·W가 바뀜, 망원 초점 → 크리티컬 | 숄더 어택 / 핸드헬드 러시(광각) / 망원 스나이프(망원) | 조명 낙하 / 로우앵글 슬라이딩 / 줌인 당기기 | 렌즈 교체 (광각·표준·망원) | 원테이크 |
| 연출감독 | 전략 CC형 | 콘티(함정) 최대 3개 | 콘티 설치 (밟으면 묶임) | NG! (받아치기) | 큐 사인 (콘티 폭발) | 리테이크 (상대를 2초 전 자리로 + 멈춤) |
| 사운드감독 | 축적 방출형 탱커 | 맞고 막을수록 사운드↑, 리버브 추가 피해, 강공격 슈퍼아머 | 저음 충격파 | 노이즈 월 (막을 때마다 게이지↑) | SOUND OVER (게이지 방출) | 동시녹음 풀레벨 |
| 조명감독 | 스턴 콤보형 | 빛 기술로 상대 노출↑ → 100이면 기절(별) | 키라이트 (3연타 빛줄기) | 백라이트 (끌어오기) | 팔로우 스폿 (4초 추적 노출) | 풀 파워 (노출 MAX) |
| 미술감독 | 지형 생성형 | 제작 포인트, 애플박스 위에서 공격력↑·하단 회피 | 애플박스 (발판, 25) | 페이크 월 (35) | 소파 드롭 (50) | 세트 체인지 (구조물 폭파) |
| 분장실장 | 자원 관리 카운터형 | 분장막이 피해 60% 흡수 | 베이스 (분장막 충전) | 파우더 블라인드 (상대 판정 축소) | 클렌징 (분장막 전부 폭발, 가드 불가) | 풀메이크업 (분장막 100) |
| 배우 | 카피형 | 상대 스킬을 두 번 보면 Q·W에 복사 | 마임 펀치 → 복사한 기술 | 스턴트 구르기(무적 통과) → 복사한 기술 | 즉흥 연기 (방금 본 기술 바로 복사) | 명연기 (상대 필살 흉내) |

**전체 기술표(피해·발동·경직·쿨타임·배우는 직급)는 [MOVES.md](MOVES.md).** 게임에서는 CHARACTER 화면과 전투 중 일시정지에서도 볼 수 있습니다.

### 타격감·연출
히트스톱, 맞은 방향 카메라 밀림, 강타 임팩트 프레임·줌, 베기 선·불꽃·링·파편, 만화 의성어(퍽! 쾅! 딱! 찰칵!), 카운터 히트, 크리티컬(FOCUS!!), 기절 별, KO 때 빙글빙글 날아감, 마무리 슬로모션, 필살 컷인, 휴대폰 진동(지원 기기)

## 조작

| | 휴대폰 | 키보드 |
|---|---|---|
| 이동 / 점프 / 앉기 | 왼쪽 방향 패드 | A D / W / S |
| **방어** | **상대 반대쪽 방향** (하단은 ↓+뒤, 점프 공격은 서서) | 같음 |
| 약공격 · 강공격 (점프 중이면 점프 공격) | 약 · 강 | J · K |
| 스킬 Q · W · E (쿨타임) | Q · W · E | L · I · O |
| 필살 R (SP 100) | R | U |
| 태그: 교체 · 어시스트 | 교체 · 어시 (방향 패드 위) | Q · E |
| 일시정지·기술표 | 화면 위 ❚❚ | ESC / P |

커맨드 콤보 (모두 같은 입력): 약약약 · 약약강(띄우기) · 약강강(날리기) · 강강(회전) · 약약Q(SP 10) · 약강Q(SP 25) · ↓+약(하단) · ↓+강(하단 다운)

## 실행·테스트

```bash
npm install
npm run dev      # 개발 서버 http://localhost:5173 (같은 와이파이의 휴대폰에서도 접속 가능)
npm test         # 테스트 52개 (전투·방어·콤보·캐릭터 7명 스킬·태그 모드·직급·밸런스) (전투 로직·콤보·KO·난이도·AI 콤보·캐릭터 6명 데이터·특수기 명중·직급별 기술·스테이지 상대·캐릭터 간 승률표)
npm run moves    # characters.ts → MOVES.md 기술표 다시 만들기
npm run build    # play/ 폴더로 빌드 → 커밋하면 GitHub Pages에 반영
```

주소 끝에 `?debug`를 붙이면 판정 박스(하늘색 = 몸통, 빨강 = 공격)가 보입니다.

### 에셋 교체
- **스프라이트**: `gfx/TextureFactory.ts`에서 캐릭터 id 키(`dp`, `director`, … / 2P색 `_alt`, 보스 `_boss`)로 만든 텍스처를 PNG 스프라이트시트(`load.spritesheet('dp', …)`)로 바꾸면 됩니다. 프레임 이름(`idle_0`, `light_1` …)과 애니메이션 키(`dp_idle` …)만 맞추면 나머지 코드는 그대로입니다.
- **효과음**: `audio/Sfx.ts`의 `sfx(key)` 키(`slate`, `hit`, `block`, `shutter` …)를 유지한 채 파일 재생으로 바꾸면 됩니다.
- **폰트**: Galmuri11 (SIL OFL 1.1, `client/src/assets/fonts`, 라이선스 `client/public/LICENSE-Galmuri11.txt`)

### 캐릭터·기술 수치
`config/characters.ts`의 기술마다 `startup / active / recovery`(프레임), `damage`, `hitstun`, `blockstun`, `kbX`, `hitbox`, `cost`, `cancelInto`(콤보로 이어질 수 있는 기술), `rank`(스테이지 모드에서 배우는 직급), `anim`(쓸 동작), `voice`(대사)를 조정합니다. 촬영감독 외 캐릭터는 `derive({...})`로 촬영감독 기술을 바탕으로 바꾸고 싶은 값만 적어 둡니다. 고친 뒤 `npm run moves`.

## 온라인 대전 계획 (PHASE 4, 아직 구현 안 됨)
- `server/`에 Node.js + Socket.IO 서버: 방 생성·6자리 코드·참가·이탈·준비·시작·종료 관리
- 서버가 `core/Match`를 직접 돌리는 **서버 권위 방식**: 클라이언트는 입력(InputState)만 보내고, 서버가 상태를 브로드캐스트 → 클라이언트는 보간해서 그림
- GitHub Pages는 정적 호스팅이라 서버를 못 돌립니다. 서버는 Render·Railway·Fly.io 같은 곳에 따로 배포하고, 게임 설정에 서버 주소를 넣는 방식이 됩니다(배포 방법은 PHASE 4에서 이 문서에 추가).
