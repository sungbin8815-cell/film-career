# ROLLING! — 픽셀 아트 촬영장 격투게임

촬영장 직업인들이 구도·녹음 문제로 다투다가 장비를 무기로 한판 붙는 2D 대전 격투게임입니다.

- **바로 플레이**: https://sungbin8815-cell.github.io/film-career/play/
- **가로 화면 전용**: 세로로 들면 "가로로 돌려주세요" 안내가 뜹니다. 안드로이드 크롬은 첫 터치 때 전체화면 + 가로 고정, 아이폰은 화면 회전 잠금을 풀고 가로로 돌려주세요. 홈 화면에 추가하면 가로 전체화면 앱처럼 열립니다.
- 기술: TypeScript · Phaser 3 · Vite (온라인 대전용 Node.js + Socket.IO 서버는 PHASE 4)

## 현재 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| PHASE 1 | 프로젝트 세팅, 메인 메뉴, 픽셀 스타일, 이동·점프·공격·방어, 체력·승패 | ✅ 완료 |
| PHASE 2 | 캐릭터 6명 (촬영·연출·사운드·조명·미술·분장), 처음부터 모두 선택 가능, 캐릭터별 밸런스 | ✅ 완료 |
| PHASE 3 | STAGE MODE: 부서 선택 → 막내로 시작 → 스테이지 5개, 깰 때마다 승진(기술·능력치 성장) → 엔딩 | ✅ 완료 (스테이지 기믹은 PHASE 5) |
| PHASE 4 | FRIEND MATCH 온라인 PVP (Socket.IO 서버, 6자리 방 코드) | ⬜ 예정 (메뉴에 잠금 표시) |
| PHASE 5 | 오프닝 컷신, 실제 효과음 에셋, 스테이지 환경 기믹 | ⬜ 예정 |

실제로 되는 것:
- **VS 모드**: START → 내 캐릭터 → CPU 상대 고르기(랜덤 가능) → 배경 5종 중 랜덤 무대에서 대전 (3판 2선승, 60초)
- **캐릭터 6명**: 촬영감독(밸런스), 연출감독(빠른 압박), 사운드감독(긴 붐·원거리), 조명감독(파워), 미술감독(공격형), 분장실장(최고 속도·연타). 캐릭터마다 장비·의상·기술·대사가 다름
- **스테이지 모드**: 부서를 고르면 `막내`로 입사 → STAGE 1~4 (크로마키 스튜디오 · 골목 야간 로케 · 사극 세트장 · 노을 옥상), 이길 때마다 `서드 → 세컨드 → 퍼스트 → 감독`으로 승진. FINAL(영화제 시상식 무대)에서 같은 부서의 `전설의 감독`과 대결 → 엔딩
  - 직급이 오르면 기술이 생기고(막내: 약·강·특·↓강 → 서드: ↓특·약약강 → 세컨드: 콤보 3개 → 퍼스트: 약강특·필살) 체력·공격력이 오름
  - 진행 상황은 브라우저에 저장 (부서마다 따로, `처음부터`로 초기화)
- **타격감**: 히트스톱(약 6 / 강 10 / 마무리 15프레임), 맞은 방향으로 카메라 밀림, 강타 임팩트 프레임·줌, 방향 있는 베기 선·불꽃·링·파편·데미지 숫자, 때린 쪽 반동, 2겹 타격음(딱+쿵), **카운터 히트**(상대 기술 시작 중에 맞히면 피해 ×1.25, 경직·히트스톱 증가, `COUNTER!`), 휴대폰 진동(지원 기기)
- 커맨드 콤보 6종 (모든 캐릭터 같은 입력, 기술은 캐릭터마다 다름), 마무리 기술 슬로모션, 필살기 컷인
- 게이지: 때리거나 맞으면 참. 특수기 25, 필살기 100 소모
- CPU AI: EASY / NORMAL / HARD (VS는 SETTINGS에서, 스테이지는 단계별로 자동)

아직 없는 것: 온라인 대전, 오프닝 컷신, 실제 효과음 파일, 스테이지 환경 기믹. 메뉴의 FRIEND MATCH는 잠겨 있고 누르면 "준비 중" 안내가 나옵니다.

## 조작

| | 휴대폰 | 키보드 |
|---|---|---|
| 이동 / 점프 / 앉기 | 왼쪽 방향 패드 (밀어서 조작) | A D / W / S |
| 달리기 | 같은 방향 빠르게 두 번 | 같은 방향 두 번 |
| 약공격 · 강공격 | 약 · 강 | J · K |
| 특수기 / ▼+특수기 | 특 / ▼ + 특 | L / S + L |
| 방어 (누르는 동안) | 방어 | I 또는 스페이스 |
| 필살기 (게이지 100) | 필살 | U |
| 직업 고유 특성 | 고유 (캐릭터마다 이름이 바뀜) | O |
| 일시정지 · 기술표 | 화면 위 ❚❚ | ESC / P |

### 커맨드 콤보 (모든 캐릭터 공통 입력)

| 입력 | 효과 | 촬영감독 예시 |
|---|---|---|
| 약 → 약 → 강 | 띄우기 | 트라이포드 어퍼 |
| 약 → 강 → 강 | 날려버리기 | 줌인 펀치 |
| 강 → 강 | 2연타 | 삼각대 회전베기 |
| 약 → 약 → 특 | SP 10, 긴 경직 | 플래시 버스트 |
| 약 → 강 → 특 | SP 25, 연타 러시 | 롱테이크 러시 |
| ▼ + 강 | 하단, 다운 | 로우앵글 스윕 |

### 직업 고유 특성 (고유 버튼 / 키보드 O)

모션만 다른 게 아니라 직업마다 싸우는 방식이 바뀝니다. 막내 때부터 쓸 수 있고, HUD 체력바 아래에 상태가 보입니다.

| 직업 | 특성 | 효과 |
|---|---|---|
| 촬영감독 | 렌즈 교체 | 누를 때마다 표준 → 망원 → 광각. 광각: 판정 넓고 빠름·피해 -15% / 망원: 사거리 +14·피해 +20%·발동 +2프레임 |
| 연출감독 | 마킹 테이프 | 바닥에 표시를 깔고, 멀리서 다시 누르면 표시 자리로 순간이동("위치로!"). 표시 위에서 공격하면 피해 +15% |
| 사운드감독 | REC → 플레이백 | 3초 녹음 동안 받은 피해(가드 포함)를 모아, 다시 누르면 30 + 녹음량×0.9 피해의 음파로 되돌려 줌 |
| 조명감독 | 조명 설치 | 8초 동안 조명 범위 안에서 강한 기술에 슈퍼아머(한 대 맞아도 안 끊김), 빛 안의 상대는 눈부셔서 발동 +2프레임 |
| 미술감독 | 세트벽 | 앞에 합판 벽: 상대 투사체·이동을 막고, 날아오는 상대는 벽에 튕겨 추가타("벽꽝!"). 3번 맞으면 부서짐 |
| 분장실장 | 분장 완성 | 맞힐 때마다 상대에게 분장이 1겹(최대 5)씩 쌓이고, 완성!으로 한꺼번에 터뜨림(겹당 14, 가드 불가) |

캐릭터마다 공격·대기·승리·특성 동작이 모두 따로 있습니다 (`gfx/charPoses.ts`, 촬영감독은 `gfx/poses.ts`).

**캐릭터별 전체 기술표는 [MOVES.md](MOVES.md)** (이름·대사·피해·발동·경직·SP·배우는 직급). 게임에서는 CHARACTER 메뉴와 전투 중 일시정지에서 볼 수 있습니다.

## 실행·테스트

```bash
npm install
npm run dev      # 개발 서버 http://localhost:5173 (같은 와이파이의 휴대폰에서도 접속 가능)
npm test         # 테스트 41개 (특성 11개 포함) (전투 로직·콤보·KO·난이도·AI 콤보·캐릭터 6명 데이터·특수기 명중·직급별 기술·스테이지 상대·캐릭터 간 승률표)
npm run moves    # characters.ts → MOVES.md 기술표 다시 만들기
npm run build    # play/ 폴더로 빌드 → 커밋하면 GitHub Pages에 반영
```

주소 끝에 `?debug`를 붙이면 판정 박스(하늘색 = 몸통, 빨강 = 공격)가 보입니다.

### 에셋 교체
- **스프라이트**: `gfx/TextureFactory.ts`에서 캐릭터 id 키(`dp`, `director`, … / 2P색 `_alt`, 보스 `_boss`)로 만든 텍스처를 PNG 스프라이트시트(`load.spritesheet('dp', …)`)로 바꾸면 됩니다. 프레임 이름(`idle_0`, `light_1` …)과 애니메이션 키(`dp_idle` …)만 맞추면 나머지 코드는 그대로입니다.
- **효과음**: `audio/Sfx.ts`의 `sfx(key)` 키(`slate`, `hit`, `block`, `shutter` …)를 유지한 채 파일 재생으로 바꾸면 됩니다.
- **폰트**: Galmuri11 (SIL OFL 1.1, `client/src/assets/fonts`, 라이선스 `client/public/LICENSE-Galmuri11.txt`)

### 캐릭터·기술 수치
`config/characters.ts`의 기술마다 `startup / active / recovery`(프레임), `damage`, `hitstun`, `blockstun`, `kbX`, `hitbox`, `cost`, `cancelInto`(콤보로 이어질 수 있는 기술), `rank`(스테이지 모드에서 배우는 직급), `anim`(쓸 동작), `voice`(대사)를 조정합니다. 촬영감독 외 캐릭터는 `derive({...})`로 촬영감독 기술을 바탕으로 바꾸고 싶은 값만 적어 둡니다. 고친 뒤 `npm run moves`.

## 온라인 대전 계획 (PHASE 4, 아직 구현 안 됨)
- `server/`에 Node.js + Socket.IO 서버: 방 생성·6자리 코드·참가·이탈·준비·시작·종료 관리
- 서버가 `core/Match`를 직접 돌리는 **서버 권위 방식**: 클라이언트는 입력(InputState)만 보내고, 서버가 상태를 브로드캐스트 → 클라이언트는 보간해서 그림
- GitHub Pages는 정적 호스팅이라 서버를 못 돌립니다. 서버는 Render·Railway·Fly.io 같은 곳에 따로 배포하고, 게임 설정에 서버 주소를 넣는 방식이 됩니다(배포 방법은 PHASE 4에서 이 문서에 추가).
